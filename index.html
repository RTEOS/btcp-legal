BTCP QuickBooks Integration

A private internal application operated by Brandenberger Tree Care Professionals.

This application is not publicly available. It is used solely by Brandenberger Tree Care Professionals to reconcile our own accounting records. It is not offered to, sold to, or installable by any other company.

What it does

It connects to our own QuickBooks Online company file and reads accounting records — invoices, income accounts and financial reports — so that our invoicing can be reconciled against our field-operations system and bookkeeping errors can be detected.

How it handles access

The application operates read-only by default. Any ability to modify accounting records is disabled unless a specific, documented, time-limited authorization is in force naming the exact operations permitted. Operations that send communications to customers are permanently disabled and cannot be enabled by any authorization.

Access uses Intuit's OAuth 2.0. No QuickBooks username or password is ever stored.
