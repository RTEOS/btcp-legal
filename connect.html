Connecting to QuickBooks

For authorized Brandenberger Tree Care Professionals personnel.

This application connects to a single QuickBooks Online company file — BTCP's own. It cannot connect to any other company.

To connect or reconnect

  1. Sign in to QuickBooks Online as an administrator of the BTCP company.
  2. Run the integration's authorization step, which redirects to Intuit's consent screen.
  3. Review the access being requested and approve it.
  4. Intuit issues a token to the application. No password is shared with or stored by the application.

If access has expired

Access tokens are short-lived and renew automatically. If the connection has lapsed entirely — because it was revoked, or went unused long enough to expire — repeat the steps above. Re-authorizing is routine and requires no support request.
